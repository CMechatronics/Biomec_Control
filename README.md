# Control. Biomec UMA

Biomec es una iniciativa de la Universidad de Málaga orientada al desarrollo de soluciones de ingeniería aplicadas a prótesis de mano electrónicas. El proyecto parte del estudio de señales electromiográficas (EMG), obtenidas a partir de la actividad muscular, para convertirlas en información útil de control.

La señal biológica se adquiere mediante un sistema de medida basado en el ADS1198 y se comunica con un microcontrolador encargado de procesarla. A partir de ese tratamiento es posible definir umbrales de activación y generar órdenes de control que permitan accionar los motores de la prótesis de forma coordinada.

El trabajo integra varias disciplinas técnicas, entre ellas mecánica, control, electrónica y diseño de sistemas embebidos.

## Objetivo del repositorio

Este repositorio reúne el trabajo del departamento de control y sirve como base para organizar el avance del proyecto, documentar decisiones técnicas y centralizar tareas, diseños y pruebas de desarrollo.

## Contexto técnico

El planteamiento del sistema se apoya en la adquisición diferencial de bioseñales, el acondicionamiento de la señal y su posterior interpretación para control. En la práctica, esto exige una interfaz fiable entre el cuerpo y la electrónica, así como un tratamiento adecuado del ruido, la amplitud de la señal y la sincronización con el sistema de actuación.

## Alcance

- Estudio y adquisición de señales EMG.
- Interfaz entre el sensor biológico y la electrónica de control.
- Procesamiento de señal para detección de umbrales y eventos.
- Integración con actuadores para el control de la mano protésica.
